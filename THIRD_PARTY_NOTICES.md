# Third-Party Notices

This app includes software written by other people. This file lists every third-party component that ships inside the app bundle, with its version, where it comes from, its license and the full text of that license. The same file is inside the app (`Contents/Resources`) and can be opened from its About window.

The app's own license is in `LICENSE` and `NOTICE`. The model weights are not listed here because the app does not include them: it downloads them on request from their original sources, as the README explains.

This file is generated by `scripts/third-party-notices.py` from the pinned dependencies: do not edit it by hand.

## Libraries under the GNU LGPL

This app uses two libraries that are covered by the GNU Lesser General Public License. Both arrive with the mlx-audio-io Python package, which Studio uses to read and write audio files at the Intermediate and Pro levels.

- **LAME** (libmp3lame 3.100), Copyright The LAME Project and its contributors, under the GNU Library General Public License version 2 or later. It is compiled into the extension module `mlx_audio_io/_core`.
- **SoX Resampler Library** (libsoxr 0.1.3), Copyright (c) 2007-2018 Rob Sykes, under the GNU Lesser General Public License version 2.1 or later. It is a separate dynamic library, `Contents/Resources/sidecar/site-packages/mlx_audio_io/.dylibs/libsoxr.0.1.2.dylib`.

You may modify these libraries and use your modified versions with this app. You can replace the libsoxr dynamic library with your own build, and rebuild the mlx-audio-io module from its source against a modified LAME. Their complete source code is published next to every release of the app, in the archive of LGPL sources on the same download page, and upstream at <https://lame.sourceforge.io/>, <https://sourceforge.net/projects/soxr/> and <https://pypi.org/project/mlx-audio-io/>. The texts of both licenses are in this file, under "Code inside the Python packages".
